# VelxioAI Agent System Guidelines

## Core Directive
Always refer to `CLAUDE.md` (`.agents/CLAUDE.md` and `CLAUDE.md`) before proposing or executing architectural, frontend, backend, or simulation changes.

## Project Vision: VelxioAI
- **Velxio** is an open-source, web-based embedded IDE and hardware emulator (supporting Arduino, ESP32, ESP32-C3, Raspberry Pi Pico / RP2040, Raspberry Pi 3, RISC-V, AVR8).
- **VelxioAI Goal**: Transform this web IDE into an **AI-native Embedded Studio** (analogous to what Cursor is to VS Code).
- Features to power with AI:
  1. **AI Circuit & Hardware Co-Pilot**: Generate, edit, and auto-wire schematics/components from natural language or requirements.
  2. **AI Code Generation & Intelligent Refactoring**: Embedded C/C++, MicroPython, Rust, and ESP-IDF assistance tailored to MCU constraints (memory, pinouts, registers, interrupts, peripherals).
  3. **Real-time Diagnostic & Self-Healing Agent**: Analyze compilation errors (`arduino-cli` / `espidf`), fix code automatically, and diagnose hardware simulation issues (floating pins, resistor values, SPICE electrical netlist bugs).
  4. **Embedded MCP / Multi-Agent Integration**: MCP server and tool bridges to allow deep automation of circuit design, code compilation, and simulation execution.

## Critical Technical Rules (from CLAUDE.md)
1. **Web Components for Boards & Components**: All interactive boards and components MUST be Web Components (`class Foo extends HTMLElement`) with a `pinInfo` getter, not plain React SVGs. Wires compute connection coordinates from `element.pinInfo`.
2. **Never Hand-Edit `components-metadata.json`**: It is auto-generated by `scripts/generate-component-metadata.ts`. Use `scripts/component-overrides.json` for custom components or property overrides.
3. **Zustand State Architecture**:
   - `useEditorStore`: Multi-file workspace (`files[]`, `activeFileId`, `openFileIds`).
   - `useSimulatorStore`: Board state, components, wires, simulation status.
   - `useCompileLogsStore`: Compiler outputs and diagnostics.
   - `useElectricalStore`: SPICE engine integration.
4. **Wokwi Libraries**: `@wokwi/elements`, `avr8js`, and `rp2040js` come from npm.
5. **Backend Compilation**: Stateless FastAPI backend running `arduino-cli` and `espidf` compilers.

## Stability & Anti-Tunnel-Vision Directive
- **Never Break Existing Features**: All AI capabilities must be non-destructive add-ons that integrate cleanly with existing stores, components, and simulation engines.
- **Holistic Impact Assessment (No Tunnel Vision)**: If something goes wrong or needs adjustment, always evaluate the full system impact to ensure the solution does not harm other components or introduce regressions in future phases.
- **Empower Zero-Knowledge Users**: The system must allow users with zero programming or electronics background to design, build, simulate, and learn hardware concepts effortlessly.
